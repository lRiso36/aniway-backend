# Aniway Backend

Networking platform to track animes user has watched and find other users by their watched animes.

## technologies

- Node.js
- Express.js
- Typescript
- MongoDB / Mongoose
- Docker

## Features

- Authentication with JWT
- User management
- Anime management
- Favorite Animes by User

## installation

```
git clone <repository_url>
cd aniway-backend
npm install

```

## dev mode

```
npm run dev
```

## prod mode

```
npm run build
npm run start
```
